## 🎯 Scénario de démonstration (10 minutes)

### Étape 1 — Dashboard (2 min)

Après connexion, vous arrivez sur le **tableau de bord** :
- Widget **alertes délais** : un dossier OQTF en urgence (deadline 20 juillet)
- Vue d'ensemble des dossiers en cours
- Emails non lus à traiter

### Étape 2 — Résumé IA d'un email (2 min)

1. Cliquez sur **Emails** dans le menu
2. Ouvrez l'email "URGENT — Notification OQTF reçue"
3. Observez le **résumé IA** automatique :
   - Client détecté : Ahmed BENALI
   - Type : OQTF
   - Urgence : Critique
   - Deadline : 20/07/2026
   - Résumé en 2 lignes

### Étape 3 — Email → Dossier en 1 clic (1 min)

1. Ouvrez l'email "Demande de RDV — refus de visa regroupement familial"
2. Cliquez sur **Créer un dossier** (bouton bleu)
3. Les champs sont pré-remplis par l'IA
4. Validez → le dossier est créé instantanément

### Étape 4 — Génération de document (2 min)

1. Allez dans **Dossiers** → Ouvrez le dossier BENALI (OQTF)
2. Cliquez sur **Générer un document**
3. Choisissez le template : "Recours contentieux"
4. Les variables sont auto-remplies (nom, dates, juridiction)
5. Téléchargez le document généré

### Étape 5 — Brouillon de réponse IA (1 min)

1. Depuis un email, cliquez sur **Rédiger une réponse**
2. L'IA génère un brouillon contextualisé au dossier
3. Modifiez si besoin, puis envoyez

### Étape 6 — Recherche jurisprudence (2 min)

1. Allez dans **Jurisprudence**
2. Recherchez : "OQTF vie privée et familiale"
3. Consultez les résultats issus de Légifrance

## 🔒 Sécurité & Conformité

- **RGPD** : toutes les données sont traçables (audit trail chaîné)
- **Multi-tenant** : vos données sont 100% isolées
- **IA locale** : aucune donnée client n'est envoyée vers un cloud tiers
- **Chiffrement** : HTTPS, headers de sécurité institutionnels
