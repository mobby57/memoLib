# GUIDE D'ONBOARDING PILOTE — 30 MINUTES POUR DÉMARRER

## MemoLib pour les avocats en droit des étrangers

**Durée totale** : 30 min (5 min setup + 10 min exploration + 15 min premier cas)

---

## ✅ AVANT DE COMMENCER

Vous avez reçu :
- [ ] Email d'accès (lien de création de compte)
- [ ] Accord de confidentialité signé
- [ ] Accès Gmail/Outlook configuré

**Si l'une manque**, contactez : support@memolib.space

---

## ÉTAPE 1 : CRÉATION DE COMPTE (5 MIN)

### 1.1 Accès à la plateforme

1. Cliquez sur le lien d'activation reçu par email
2. Remplissez le formulaire :
   - Email professionnel
   - Mot de passe (8+ caractères, 1 majuscule, 1 chiffre, 1 spécial)
   - Acceptez les CGU ✅

3. Cliquez « Créer mon compte »

### 1.2 Vérification email

1. Un email de vérification est envoyé
2. Cliquez le lien dans l'email (valide 24h)
3. Vous êtes connecté à MemoLib ! 🎉

### 1.3 Premier accès

1. Bienvenue sur le dashboard
2. Cliquez « Connecter Gmail » ou « Connecter Outlook »
3. Autorisez MemoLib à accéder vos emails (ne pas s'inquiéter — c'est chiffré)
4. Sélectionnez les dossiers à synchroniser

---

## ÉTAPE 2 : EXPLORER L'INTERFACE (10 MIN)

### 2.1 Le menu principal

| Section | Rôle |
|---------|------|
| **Dashboard** | Vue d'ensemble de vos dossiers et alertes |
| **Emails** | Boîte de réception centralisée (Gmail + Outlook) |
| **Dossiers** | Gestion de vos cases de clients |
| **Documents** | Génération de courriers (6 templates) |
| **Contacts** | Annuaire des clients |
| **Analyse IA** | Résumés, suggestions, recherche jurisprudence |
| **Paramètres** | Profil, préférences, données |

### 2.2 Le dashboard

**À voir** :
- 🔴 **Alertes urgentes** : Délais critiques (J-3)
- 🟠 **Alertes à valider** : Deadlines imprécises (« brefs délais »)
- 📧 **Emails non traités** : À trier
- 📊 **Statistiques** : Dossiers, clients, actions

### 2.3 La boîte emails

**À faire** :
1. Cliquez « Emails »
2. Voyez tous vos messages Gmail + Outlook mélangés
3. Cliquez sur un email
4. À droite : analyse IA (type de dossier, deadline, confiance)

### 2.4 Créer votre première action

1. Allez à « Dossiers »
2. Cliquez le bouton bleu « + Nouveau dossier »
3. Remplissez :
   - **Nom du client** : Prénom Nom
   - **Type** : Asile, OQTF, Nationalité, etc.
   - **Description** : Contexte court
   - **Échéance** : Date limite
4. Cliquez « Créer »

✅ Votre premier dossier existe !

---

## ÉTAPE 3 : TRAITER VOTRE PREMIER CAS (15 MIN)

### 3.1 Scénario : Rejet d'asile — Appel CNDA

Imaginons que vous recevez cet email :

```
De : client@email.com
Objet : Rejet asile — urgent !
Corps :
"Maître, l'OFPRA a rejeté ma demande d'asile le 10 septembre.
Je dois faire quoi pour contester ?"
```

### 3.2 Actions dans MemoLib

**1. Importer l'email**
- Allez dans « Emails »
- Trouvez l'email du client
- Cliquez « Créer un dossier »

**2. MemoLib suggère** :
- ✅ Type : **Asile → Appel CNDA**
- ✅ Deadline : **10 octobre 2026** (30 jours)
- ✅ Confiance : **95%**

**3. Vérifier la suggestion**
- Lisez l'analyse IA (à droite)
- Vérifiez que le type est correct
- Confirmez la deadline

**4. Valider et créer le dossier**
- Cliquez « Créer ce dossier »
- Un dossier s'ouvre automatiquement

**5. Explorer le dossier**
- Onglet **Résumé** : Email résumé par l'IA
- Onglet **Checklist** : Actions à prendre
  ```
  ☐ Consulter les articles L. 521-1 CESEDA (délais CNDA)
  ☐ Préparer le mémoire en défense
  ☐ Joindre : Copie décision OFPRA, documents justificatifs
  ☐ Envoyer le recours à la CNDA
  ```
- Onglet **Timeline** : Historique des actions
- Onglet **Jurisprudence** : Cas similaires (recherche Légifrance)

**6. Générer un recours**
- Cliquez « Documents »
- Sélectionnez **Recours CNDA** (template)
- Cliquez « Générer »
- Un brouillon s'ouvre avec champs pré-remplis
- Modifiez et téléchargez

✅ **Vous avez traité votre premier cas !**

## GUIDES RAPIDES

### Comment connecter Gmail ?

1. Dashboard → Paramètres → Intégrations
2. Cliquez « Connecter Gmail »
3. Autorisez MemoLib (lecture seule)
4. Retournez à Emails

### Comment générer un document ?

1. Allez à « Documents »
2. Cliquez sur un template (ex: Recours gracieux)
3. Cliquez « Générer »
4. Remplissez les champs
5. Cliquez « Télécharger PDF »

### Comment créer une alerte personnalisée ?

1. Allez à « Paramètres »
2. Cliquez « Alertes »
3. Créez une règle (ex: « OQTF → Alerte J-7 »)
4. Validez

### Comment exporter mes données ?

1. Allez à « Paramètres »
2. Cliquez « Données »
3. Sélectionnez « Exporter tout »
4. Téléchargez le ZIP (JSON + CSV)
