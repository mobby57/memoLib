# MemoLib — Roadmap Features

## Q3 2026 — Priorité haute

- [ ] OCR intelligent (photo courrier → extraction données)
- [ ] Dictée vocale → notes structurées
- [ ] Relance automatique pièces manquantes (J+7)
- [ ] Réponse automatique au client ("pièce reçue 3/9")
- [ ] Espace client : upload documents + suivi progression
- [ ] Notification SMS urgences (OQTF 48h)
- [ ] Détection conflits d'intérêts
- [ ] Calcul automatique honoraires (temps × taux)
- [ ] Timeline visuelle du dossier
- [ ] Signature électronique intégrée (Yousign)

## Q4 2026 — Mobile & Communication

- [ ] App mobile React Native (iOS/Android)
- [ ] Mode hors-ligne (consultation dossiers)
- [ ] Sync Google Calendar bidirectionnel
- [ ] Chat client intégré
- [ ] Prise de RDV en ligne (Calendly-like)
- [ ] Questionnaire d'intake client
- [ ] Rappel audience J-1 avec résumé dossier
- [ ] Dark mode complet
- [ ] Widget notifications mobile

## Q1 2027 — IA avancée

- [ ] Rédaction complète de recours (IA)
- [ ] Analyse de risque par dossier
- [ ] Suggestion de stratégie juridique
- [ ] Simulateur de chances (stats tribunal)
- [ ] Veille juridique personnalisée
- [ ] Traduction automatique documents (arabe/turc/chinois)
- [ ] Préparation entretien OFPRA
- [ ] Résumé d'audience (dictée → structure)
- [ ] Benchmark anonymisé ("vous traitez 20% plus vite")

## Q2 2027 — Intégrations & Conformité

- [ ] Intégration RPVA (dépôt conclusions)
- [ ] Intégration Télérecours (suivi TA/CAA)
- [ ] Intégration ANTS (suivi titres séjour)
- [ ] Aide juridictionnelle (calcul éligibilité + formulaire)
- [ ] Convention d'honoraires auto-générée
- [ ] Export comptable FEC
- [ ] Certification ISO 27001
- [ ] 2FA obligatoire (TOTP)

## Q3 2027 — Pilotage & Scale

- [ ] Dashboard financier (CA, marges, prévisions)
- [ ] Rentabilité par type de dossier
- [ ] Rapport mensuel auto-généré (PDF)
- [ ] Alerte préfecture temps réel (délais traitement)
- [ ] Dossier partagé inter-cabinets
- [ ] Duplication de dossier type
- [ ] Recherche full-text tous documents
- [ ] Facturation récurrente (provisions)
- [ ] Relance impayés automatique
- [ ] Paiement en ligne client
- [ ] Avis/témoignage post-clôture
