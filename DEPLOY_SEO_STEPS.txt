1. VARIABLES D'ENVIRONNEMENT VERCEL
------------------------------------------------------------
Vercel → Projet → Settings → Environment Variables

  NEXT_PUBLIC_APP_URL = https://memolib.space
  NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION = (ton code Google)
  
  Ne PAS ajouter NEXT_PUBLIC_SHOW_DEMO en production.
  (Ajouter NEXT_PUBLIC_SHOW_DEMO=true uniquement en Preview si besoin)


2. PUSH SUR GITHUB
------------------------------------------------------------
  cd C:\Users\moros\Desktop\memolib
  git add -A
  git commit -m "fix(seo): refonte SEO + UX pages publiques"
  git push

  Vercel déploie automatiquement.


3. GOOGLE SEARCH CONSOLE — VÉRIFICATION
------------------------------------------------------------
a) Va sur https://search.google.com/search-console
b) Ajoute propriété → "Préfixe d'URL" → https://memolib.space
c) Méthode "Balise HTML" :
   - Copie le content (ex: abc123xyz456)
   - Colle-le dans la variable Vercel NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION
   - Redéploie
   - Clique Vérifier

   OU méthode "DNS TXT" (Spaceship) :
   - Spaceship → Domains → memolib.space → DNS Records
   - Type: TXT | Host: @ | Value: google-site-verification=TONCODE
   - Attends 10 min
   - Vérifie avec : nslookup -type=TXT memolib.space
   - Retourne sur Search Console → Vérifier
