# Application Flow (AppFlow) - MemoLib
## Parcours Utilisateur Principal (Avocat)
1. **Connexion** : L'avocat se connecte via Clerk.
2. **Tableau de bord** : Vue d'ensemble des dossiers actifs et des tâches.
3. **Gestion Client** : Création d'une fiche client (nom, coordonnées, dossier).
4. **Génération de documents** : Sélection d'un modèle, remplissage automatique via l'IA.
5. **Facturation** : Génération de factures, suivi des paiements, relances automatiques.
